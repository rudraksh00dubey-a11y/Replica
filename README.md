# Footwear Showcase & Landing Page Replica

A modern, responsive e-commerce landing page built to demonstrate UI layout design, responsive structure, and interactive product variant selection.

🔗 **Live Demo:** [replica-theta-eight.vercel.app](https://replica-theta-eight.vercel.app/)

---

## 📌 Features

- **Responsive Layout:** Structured navigation bar, hero presentation section, and footer designed for multiple screen resolutions.
- **Interactive Product Variants:** Dynamic selector for product sizes and colorways.
- **Design-to-Code Execution:** Clean typography, spacing, and brand-focused visual hierarchy.
- **Fast Performance:** Lightweight static assets deployed for near-instant load times.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure (`<main>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3 / Modern Layouts:** Flexbox and Grid for precise alignment and responsive positioning.
- **JavaScript (Vanilla / Modern DOM):** Interactive color and sizing toggles.
- **Vercel:** Deployment and hosting.
